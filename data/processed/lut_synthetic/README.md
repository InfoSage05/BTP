# lut_synthetic_pretraining.csv — Stage 0 output

**Synthetic data generated from the 2006 Groeneveld LUT — for pretraining
only, never treated as real experimental measurements.**

## What this is
A large, clean (P, G, X, D) -> CHF table generated by:
1. Building a trilinear interpolator over the 24x21x23 LUT grid
   (`data/chf_long_clean.csv`), after excluding the 504 placeholder-zero
   cells (no experimental coverage there) as invalid.
2. Sampling points densely within the LUT's covered (P, G, X) range, and
   **only keeping a sample if all 8 grid cells surrounding it were real,
   valid LUT data** — no synthetic point is generated from an
   imputed/interpolated-through-invalid region.
3. Extending into diameter-space (the LUT itself has no D axis — it's
   normalized to D=8mm) using the published diameter-correction exponent
   from Tanase et al. (2009), *Diameter effect on critical heat flux*,
   Nucl. Eng. Design 239: `CHF_D = CHF_(D=8mm) * (8/D)^n`, with `n` looked
   up per (P, G, X) bin from their own Table 3
   (`data/raw/testing/tanase2009_diameter_correction_exponent_grid.csv`).
   This is a deterministic physics formula applied to LUT-derived values —
   **no experimental data point from that test-only file enters this
   output**, only the published exponent.

## Known, deliberate limitation
**No heated-length (L) dependence.** The base LUT is L-independent by
construction, and no well-documented L-correction formula is on file in
this repo. Output rows have no `L_mm` / `L_over_D` column. Real L-variation
is only present in the fine-tuning datasets — this synthetic corpus should
not be treated as covering that axis.

## Columns
`P_kPa, G_kg_m2s, X, D_mm, CHF_kW_m2, diameter_correction_exponent_n,
P_reduced, rho_l_kg_m3, rho_g_kg_m3, density_ratio` (fluid = water
throughout, via CoolProp).
