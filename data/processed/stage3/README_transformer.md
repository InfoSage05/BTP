# Stage 3 results -- Transformer ensemble (4 members)

Same recipe as the MLP ensemble (`README.md` in this folder) but N_MEMBERS=4
instead of 8, given the ~30-40x higher per-member training cost on this
CPU-only setup (documented in `ensemble_transformer.py`).

## Notable: ensembling genuinely rescued hardik2017
Every other context shows the same pattern as the MLP ensemble (members
converge to near-identical solutions, ensemble barely beats single-model
average, coverage badly miscalibrated ~12-28%). hardik2017 is the
exception: single-model std across the 4 seeds was 0.211 (huge, relative to
other contexts' ~0.001-0.007), meaning individual fine-tuning runs on this
11-row test set varied wildly (Stage 2's single run got R2=-0.05). Here,
averaging across genuinely disagreeing members produced both a much better
point estimate (0.378) and, notably, much better calibration (63.6%
coverage vs. the usual 12-28%) -- this is what ensembling is *supposed* to
do, and it only showed up where individual runs were actually unstable
enough to disagree.

## Full MLP vs. Transformer comparison (ensemble R2, all stages)

| Context | MLP ensemble (N=8) | Transformer ensemble (N=4) |
|---|---|---|
| core_interp | 0.963 | **0.968** |
| core_extrap | 0.916 | **0.953** |
| hardik2016_coils_r123 | 0.560 | **0.736** |
| hardik2017_straight_tubes_r123 | **0.481** (single-model; ensemble not directly comparable given the Transformer's rescue effect above) | 0.378 |
| kaeri_uniform_water | 0.907 | 0.903 |
| kaeri_nonuniform_water | **0.864** | 0.845 |
| zhao2020_tubes_water | 0.890 | **0.892** |

Transformer wins or ties on 5/7, most clearly on core_extrap (+0.037) and
hardik2016 (+0.176) -- the two contexts where the extra capacity/attention
seems to matter most. MLP still wins on hardik2017 and kaeri_nonuniform,
though by smaller margins. Given the Transformer costs ~30-40x more to
train, this is a real trade-off, not a clean "Transformer wins" story --
but with the properly-budgeted pretraining (fixed after the first,
unfairly-equal-epoch comparison), the Transformer's case is stronger than
the initial Stage 1 read suggested.
