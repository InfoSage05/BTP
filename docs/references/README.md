## 2026-09-01 extraction log

Extracted data from the 5 engineered-surface papers listed above using `pdftotext -layout` (exact text extraction, not visual/OCR reading of rendered pages) so every numeric value in the resulting CSVs traces to real text in the source PDF. Where a paper only gives a value as a chart (not text or a table), it was left out of the CSV rather than estimated from the figure — see the per-row notes in `data/raw/external/README.md` for exactly which fields hit this limit (e.g. 3 of 4 contact-angle values in the Ali et al. 2018 extraction; all per-sample absolute CHF values in the Son et al. 2020 extraction).
