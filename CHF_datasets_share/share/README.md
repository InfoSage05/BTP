# CHF datasets collected for the B.Tech project

This folder holds every point-level CHF dataset we have gathered, extracted or been
given so far. `MANIFEST.csv` lists the same files in a form you can open in Excel.

## Totals

29,049 unique experimental CHF data points across 12 datasets. If you remove the 136
exact duplicate rows sitting inside the NRC database, the figure is 28,913.

That total is 28,470 (the merged master file) plus 100 engineered-surface rows, 156
Hardik helical-coil rows, 55 Hardik straight-tube rows and 268 digitised Pioro rows,
none of which are inside the merged file.

Separately there is the 2006 Groeneveld look-up table at 11,592 grid rows. We have not
counted it above because it is a smoothed table rather than a set of measurements.

Adding up the study counts given for each dataset below gives 124 source studies. Some
of the large compilations may draw on the same historical experiments, so treat 124 as
an upper bound rather than a count of distinct laboratories.

Synthetic data is not included. The project does contain 300,000 rows sampled from the
look-up table for pre-training and 7,114 Gaussian-Process-augmented rows, but both are
generated by our own code, so they are model output rather than collected data.

## Folder layout

    01_merged/                            the seven point-level sources merged into one schema
    02_flow_boiling/                      flow-boiling sources as received or extracted

## Why the merged file and the separate files are both here

`01_merged/master_chf_dataset.csv` is what we actually model on. It holds 28,470 rows
and 51 columns, with pressure in kPa, mass flux in kg/m2s, CHF in kW/m2, and lengths
and diameters in mm. Every conversion factor came from the source documentation; we did
not guess any units. `01_merged/merge_report.md` lists the row counts and column
coverage.

We are sending the individual source files as well, for three reasons.

The merge loses the surface data. The master schema has no contact-angle column at all,
and its roughness column is filled on only 0.61% of rows. The engineered-surface data,
which is the subject of the paper, only survives intact in `03_`.

Provenance matters for what we found. On the engineered-surface set, which averages
about six or seven rows per publication, knowing only which study a row came from
accounts for roughly 80% of the variance in log CHF. Any analysis that pools these
sources without tracking where each row came from will run into that. Note that
`source_dataset` is filled on all 28,470 rows
of the master, but `reference_id` is filled on 26,118 of them (91.7%), and none of the
pin-fin rows carry it, so per-study work on pin-fin needs the separate file.

Extractions should be checkable. Each hand-extracted paper is a separate file under
`per_paper/`, so any row can be traced back to the paper it came from.

Each extraction was checked against the parameter ranges that Serrao et al. (2025),
Nucl. Eng. Des. 435, 113924 publish for the same studies. Most agreed. Some could only
be checked partially, because the paper concerned publishes certain values in figures
rather than in text: Kim et al. 2019 give per-specimen CHF only in a figure, and Zhang
et al. 2023 do not publish roughness. One extraction disagrees outright and is
described below.

For the five papers extracted in the September 2026 pass we used `pdftotext -layout`,
so every number in those files traces to real text in the PDF rather than to a reading
of a rendered figure. Where a paper gave a value only as a chart, we left the field
empty instead of estimating it.

## 04_holdout_digitized, 268 rows

`pioro2002_r134a_horizontal_vertical_chf_DIGITIZED.csv` comes from Pioro, Groeneveld,
Leung et al., IJHMT 45 (2002) 4435-4450. It adds two things nothing else here has,
R-134a as a fluid and horizontal against vertical tube orientation.

There is no data table in that paper. The values were read by eye off the scatter plots,
so expect roughly 5 to 10 per cent error on both axes. We have only ever used it to
check how models behave out of distribution, never for training. Its own notes file is
in the same folder.

## 05_lookup_table_reference, 11,592 rows

The 2006 Groeneveld CHF look-up table, from Groeneveld et al., Nucl. Eng. Des. 237
(2007) 1909-1922. `groeneveld_2006_lut_long_format.csv` is the flattened one-row-per-
grid-point version we work from, and `groeneveld_2006_chf_lookup_table.xlsx` is the
original spreadsheet. The grid is 24 pressures by 21 mass fluxes by 23 qualities.

We kept it out of the merged file on purpose. It is a smoothed, interpolated table
rather than raw measurement, and it is not independent of the NRC database, since both
are built from the same historical experiments. Merging the two would count the same
work twice.

504 of its rows have CHF equal to zero, all of them at quality 1.0. Those are an
all-steam placeholder rather than a measurement, which leaves 11,088 usable rows.

## Things worth knowing before using any of this

**One file had the wrong fluid label, now corrected.** We had this dataset filed as
R-123 under the name `hardik2016_helical_coils_r123_lowpressure_chf.csv`. It is water.
The source paper is Hardik & Prabhu, "Critical heat flux in helical coils at low
pressure", Appl. Therm. Eng. 112 (2017) 1223-1239, which states in its abstract that the
work uses water as the working medium and never mentions R-123 anywhere. The file also
matches that paper's Table 4 exactly: 47, 29, 18, 22, 31 and 9 points for coils 1 to 6,
totalling 156, with a mass flux range of 92 to 1241 kg/m2s. Its CHF values run 286 to
2984 kW/m2, which is the right order for water and roughly ten times our confirmed
R-123 sets at 37.7 to 419.8 kW/m2. The file is now named
`hardik2017_helical_coils_water_lowpressure_chf.csv`. The rows themselves were never
touched, only the label.

**Kam et al. 2015 disagrees with the published range.** That paper's own text gives CHF
of 1020 for bare stainless steel, 940 for Zircaloy-4, 1230 for SiC at 400 nm and 1470
kW/m2 for SiC at 1 micron. Serrao et al. (2025) quote 660 to 1223 for the same study.
Our file holds the values as printed in the paper, so the disagreement is upstream of us
and we have not resolved it. Doing so means digitising the paper's Figure 7. Until then
neither set of numbers should be leaned on.

**Two versions of the NRC database are included.** `nrc_groeneveld_24579pt` is the file
as transcribed, and it is the one inside the merged master.
`nrc_groeneveld_deduplicated_24443` has 136 exact duplicate rows removed, which are
identical experiments appearing under different reference IDs and which inflate scores
under random splitting. We have not yet pushed that deduplication through into the
merged file. We are flagging it rather than quietly fixing it.

**The Pioro file is digitised rather than measured**, as described above.

## What we left out, and why

| Left out | Reason |
|---|---|
| Synthetic data, 300,000 and 7,114 rows | Generated by our own code. The augmented set was also filtered for agreement with grid interpolation, so it cannot be used as independent evidence about that baseline |
| Source-summary tables: Serrao ranges, Liang nanofluid, supercritical water and CO2, narrow channel, NUREG Table 4-2, Tanase, Furlong | These give parameter ranges and study metadata but no point-level CHF. We keep them as provenance and as a list of things worth chasing |
| NUREG Table 4-1 sample, 21 rows | All 21 match rows already in the NRC database exactly on diameter, heated length, pressure, mass flux, quality, inlet subcooling and CHF. Both digitise the same Lowdermilk 1958 experiment. Including them would put identical rows under two different source labels |
| Helical minichannel evaporator logs, 32 runs | What the rig recorded is heater power, not heat flux. Converting it needs heated-area assumptions per geometry that we did not think were defensible for 32 rows |
| Son et al. 2020 | Reports CHF enhancement as a percentage only, never an absolute value in kW/m2 |
| Ramakrishnan et al. 2026 | Ten flow-boiling points with no per-row roughness |
| The reference library, 35 PDFs and one saved web page | Publisher copyright. The citations above should be enough to find any of them |
